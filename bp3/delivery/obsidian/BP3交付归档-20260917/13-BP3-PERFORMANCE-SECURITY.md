# 虚拟乌托邦 BP3 性能与安全

## 性能测试

### M2事务微基准

- Avatar状态更新：500次
- Avatar更新耗时目标：小于3000ms
- 留言创建：300条
- 留言列表读取：100条
- 留言读写耗时目标：小于3000ms

执行：

```powershell
cd H:\BP2\bp3\p2
npm run test:perf
```

### M3并发联调

M3 E2E发送40个并发Avatar状态更新，要求全部成功且总耗时小于8000ms。
测试结果记录在E2E JSON输出中。

## 安全检查

- 未登录请求返回401。
- 客户端伪造`authorUserId`无效，留言作者始终来自Phase5身份。
- viewer不能删除他人留言。
- 私密家园留言读取返回403。
- 非主人不能修改门锁、访客或访问规则。
- 重复任务奖励不会重复写入背包。
- 并发库存扣减只允许一个请求成功。

## 组合回归

```powershell
H:\BP2\bp3\p0 测试
H:\BP2\bp3\p1 测试
H:\BP2\bp3\p2 测试
```

M3 E2E会同时启动M1、M2、M3服务并检查各模块数据表兼容。
