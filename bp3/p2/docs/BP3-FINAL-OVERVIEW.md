## 模块

| 模块  | 范围                       | 目录      |
| ----- | -------------------------- | --------- |
| M1 P0 | 语音、家园权限、门锁、访客 | `bp3/`    |
| M2 P1 | 事件、任务、资源、背包     | `bp3/p1/` |
| M3 P2 | Avatar动作表情、家园留言板 | `bp3/p2/` |

三个模块共享BP3独立数据库，但使用独立服务入口和独立数据表前缀：

```text
bp3_       M1
bp3_p1_    M2
bp3_p2_    M3
```
