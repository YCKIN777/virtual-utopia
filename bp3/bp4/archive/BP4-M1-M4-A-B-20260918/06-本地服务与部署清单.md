## 2. 推荐启动顺序

1. Phase5身份与持久化服务。
2. BP4-M1。
3. BP4-M2。
4. BP4-M3。
5. BP4-M4。
6. 模块A。
7. 模块B。
8. BP4-M5。

模块B依赖模块A提供家园访问判定。模块A必须先启动。

## 4. 数据目录

```text
M3：H:\BP2\bp3\bp4\m3\data\bp4_m3.sqlite
M4：H:\BP2\bp3\bp4\m4\data\bp4_m4.sqlite
```

## 5. 外部依赖

- PostgreSQL：M1迁移和M2备份的真实目标。
- mediasoup：M2媒体集群。
- TURN：M2语音中继。
- Phase5：身份认证。
- Node.js与SQLite `node:sqlite`：本地服务和模块存储。

## 6. 回归顺序

```text
M1 -> M2 -> M3 -> M4 -> 模块A -> 模块B -> M5
```

每次部署后按各模块README执行：

```powershell
npm run check
npm run build
npm run test:e2e
```

不含前端的模块可跳过`npm run build`。
