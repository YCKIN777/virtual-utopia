# BP4 环境变量说明

## 1. 通用

```text
PHASE5_BASE_URL=http://localhost:3300
```

所有依赖Phase5身份的服务都应使用同一Phase5地址。

## 2. BP4-M1

```text
BP4_M1_HOST
BP4_M1_PORT
BP4_M1_TICKET_SECRET
BP4_M1_TICKET_TTL_SECONDS
BP4_DATABASE_URL
BP4_SQLITE_PATH
BP4_MIGRATION_BATCH_SIZE
PHASE5_BASE_URL
```

## 9. 密钥约束

- M1、M2、M3、M5、模块A和模块B的ticket secret必须按部署拓扑保持一致。
- 生产环境必须替换示例密钥和TURN密码。
- PostgreSQL连接串和Phase5地址不得写入冻结归档。
