# 虚拟乌托邦 BP4 阶段性汇总报告

## 1. 报告范围

本报告覆盖：

- BP4-M1平台底座。
- BP4-M2语音生产化与运维底座。
- BP4-M3世界运营后台。
- BP4-M4内容模板、PWA和数据看板。
- BP4附加模块A玩家家园归属与访问权限。
- BP4附加模块B玩家社交聊天系统。

同时记录已完成的BP4-M5 3D世界与家园搭建里程碑，作为现有工程能力补充。

## 2. 总体结论

BP4已从BP3单机验收系统升级为具备生产化基础、实时通信、运营管理、3D世界、家园权限和社交聊天能力的平台。

主要成果：

- PostgreSQL迁移工具和数据校验框架。
- 统一ticket与WebSocket实时通道。
- mediasoup多Worker、TURN、监控、告警和备份脚本。
- 世界、家园、账号和玩家状态运营后台。
- 内容模板、PWA离线缓存和数据看板。
- 50户3D家园搭建和Avatar实时位姿。
- 家园私有、好友可见、公开三档权限。
- 世界公屏、家园私有频道和玩家私聊。

## 4. 关键链路

### 实时链路

```text
Phase5/BP4身份
  -> ticket
  -> WebSocket
  -> subscribe/resume/ack
  -> presence / Avatar / voice / home / chat event
```

### 家园权限与聊天联动

```text
模块B家园频道订阅
  -> 模块A /my-access?action=view
  -> 私有/好友/公开判定
  -> 允许或拒绝频道进入
```

### 3D家园搭建

```text
M5 Three.js世界
  -> 地块选择
  -> 5×5网格放置
  -> 布局持久化
  -> home.layout.updated实时事件
```

## 6. 当前限制

- 本机未安装PostgreSQL服务，M1迁移E2E使用内存目标适配器，真实迁移链路由PostgreSQL部署环境执行。
- 本机未安装PostgreSQL客户端，M2备份E2E执行dry-run，真实备份和恢复需在部署环境验证。
- 模块A的M3面板采用独立扩展页，不修改冻结的M3前端。
- 模块A和模块B的ticket/hub复用M1代码，但在各自服务中运行，不修改M1服务。
