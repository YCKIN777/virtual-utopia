# 虚拟乌托邦 BP1~BP3 项目全景总览

## 1. 项目定位

虚拟乌托邦是网页端3D虚拟世界与多人家园平台。项目从场景化原型逐步演进为包含身份、持久化、3D家园、语音、权限、任务、背包、Avatar互动和留言板的一体化系统。

最终形态包含：

- 五十户山林庄园城镇3D世界。
- 中心生活广场、溪流、连廊、山体和750棵实例树木。
- Phase5身份与数据持久化。
- 家园访问、门锁、访客申请和临时授权。
- 世界语音、事件任务、资源采集和背包。
- Avatar动作表情与家园留言板。

## 2. 版本演进

### BP1：基础工程与六场景

BP1完成：

- Vue 3、Vite、Vue Router、TailwindCSS前端工程。
- Express后端与PostgreSQL Schema占位。
- HIG基础组件体系。
- Canvas等轴测网格和SVG六点位地图。
- 大院、议事亭、资源墙、书屋、小屋、远林六个场景容器。
- 桌面与移动端响应式基础。

阶段一验证了工程结构、设计系统、地图交互和场景路由，但尚未接入真实Agent、RAG和持久化。

### BP2：智能协作与持久化世界

BP2依次完成：

1. 分支Agent：阿禾、知予、叙白、岁安、风禾及场景边界。
2. 内存会话：公共会话与小屋私聊隔离、TTL和容量控制。
3. RAG知识库：文档加载、分块、确定性向量、Chroma检索。
4. RAG增强Agent：通过开关向System Prompt注入召回片段。
5. Phase5持久化：SQLite用户、会话、文档元数据和RAG日志。
6. Phase6网关：统一鉴权、world快照、presence、聊天和审计。
7. Three.js世界：50户木屋、广场、溪流、连廊、山体与树木。
8. 家园编辑器、Avatar同步和世界文字聊天。

BP2最终形成了可漫游、可装扮、可同步、可持久化的3D世界。

### BP3：实时社交与家园运营

BP3分三个阶段交付：

| 阶段  | 范围                   | 核心结果                          |
| ----- | ---------------------- | --------------------------------- |
| M1 P0 | 语音、家园权限、门锁   | mediasoup SFU、访客审批、临时邀请 |
| M2 P1 | 事件、任务、资源、背包 | 事件触发、任务奖励、库存事务      |
| M3 P2 | Avatar动作、留言板     | 动作同步、留言权限、全链路验收    |

BP3保持独立目录、独立端口和独立数据表前缀，不修改BP2冻结基线。

## 3. 系统架构

```text
Browser
  -> BP2/Bot UI
  -> Phase5身份与持久化
  -> Phase6网关

BP3 M1
  -> /api/bp3
  -> voice/signaling + home access

BP3 M2
  -> /api/bp3/p1
  -> events + tasks + resources + inventory

BP3 M3
  -> /api/bp3/p2
  -> avatar state + home messages
```

数据层：

```text
Phase5 SQLite
  users / chat_sessions / knowledge_documents / rag_logs

BP3 SQLite
  bp3_*      M1
  bp3_p1_*   M2
  bp3_p2_*   M3
```

## 4. 能力全景

### 身份与权限

- admin、editor、viewer角色。
- 服务端身份和权限校验。
- 地块归属、访客白名单、黑名单、申请审批和门锁。
- viewer只能漫游、参与公开互动和申请访问。

### 3D世界

- 第三人称漫游、俯视、广场、家园和室内样板。
- 昼夜、雾气、风动和LOD实例树木。
- 家园编辑、家具持久化和多人Avatar同步。

### 实时社交

- 世界文字聊天。
- mediasoup世界语音频道。
- Avatar待机、行走、动作和表情状态。

### 世界运营

- 世界事件和事件提示。
- 任务领取、资源采集、任务进度和奖励。
- 背包容量、物品堆叠、库存事务和并发扣减。
- 家园留言板及访问权限控制。
