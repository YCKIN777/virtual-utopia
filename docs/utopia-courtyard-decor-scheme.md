# 虚拟乌托邦 · 庭院装饰小品方案（三类宅院差异化）

> 迭代范围：**仅新增庭院视觉装饰小品**。不改地块坐标、宅院边界、碰撞盒、居民 AI 闲逛逻辑、
> 相机漫游、后端、注册审批、聊天、人设；不新增复杂动画。
> 代码入口：`frontend/src/virtual-utopia/webgl/decorations/courtyardDecor.js`
> 自测：`scripts/verify-courtyard-decor.mjs`

## 2. 三类宅院的差异化偏好

| 组团 | 标志性小品（优先落位） | 补充 | 语汇意图 |
| --- | --- | --- | --- |
| **台地** `terrace` | 石凳 ×2 · 果树灌丛 ×2 | 石板 ×2 | 开阔、向阳、有人烟：坐得下、有果木 |
| **临溪** `stream` | 岸边景观石 ×2 · 矮竹丛 ×2 | 石板 ×2 | 亲水、轻盈：近水多石、竹影摇曳 |
| **崖边** `cliff` | 大块毛石 ×2 · 简易石灯 ×1 | 石板 ×2 | 粗粝、隐居：大石镇地、一盏孤灯 |
| 森林 `forest` | 石凳 ×1 · 果树灌丛 ×2 · 景观石 ×1 | 石板 ×2 | 复用台地语汇（该组团用的就是台地系宅院模型） |

差异是**互斥**的，不是简单叠加：台地**没有**毛石/石灯，临溪**没有**石凳/毛石，崖边**没有**矮竹/果树。

> 石灯**不带光源**（纯石头造型）。刻意不接点光/emissive：本项目已有灯笼 + 昼夜系统，
> 不在这轮去动它，避免碰到"原有业务"。

## 3. ThreeJS 材质参数（小品专用）

**核心策略：材质零新增显存** —— 全部复用 `manorMaterials` 的共享程序化贴图
（`stone` / `slab` / `bamboo`），只换基色与粗糙度；每个「组团 × 角色」只建 1 份材质。

| 角色 | 基色 `tint` | roughness | metalness | bumpScale | 贴图来源 |
| --- | --- | --- | --- | --- | --- |
| `stool` 石凳 | `#8f8c86` | 0.98 | 0 | 0.06 | `stone` |
| `slab` 石板 | `#a9a49c` | 0.94 | 0 | 0.05 | `slab`（= 毛石图） |
| `bambooClump` 矮竹丛 | `#9a9a74` | 0.92 | 0 | 0.035 | `bamboo` |
| `landscapeRock` 景观石 | `#85827c` | 1.00 | 0 | 0.07 | `stone` |
| `stoneLantern` 简易石灯 | `#96938c` | 0.98 | 0 | 0.06 | `stone` |
| `boulder` 大块毛石 | `#7d7a75` | 1.00 | 0 | 0.08 | `stone` |
| `fruitShrub` 果树灌丛 | `#7f9a6a` | 0.95 | 0 | 0.05 | `bamboo`（绿调） |

- **组内色偏**：基色与 `MANOR_GROUP_TINTS[group]` 按 35% 插值，保证小品和该组团宅院本体是一套色系
  （台地偏暖、临溪偏灰、悬崖偏冷），但不会跳色。
- **低饱和哑光**：`metalness` 全 0、`roughness` 0.92–1.0，沿用宅院材质的调性。
- **贴图通道复用**：`map` + `bumpMap` + `roughnessMap` 三张都取自共享贴图集（颜色图兼作凹凸图），
  **本模块不产生任何新贴图**。
- 建材质代码：`createDecorMaterials({ library, group })`，逐角色 `MeshStandardMaterial`。

## 4. 落位规则（怎么保证"不阻挡、不穿模、不越界"）

所有几何都是**实测当前场景**得到的，不做任何硬编码坐标：

| 量 | 来源 | 用途 |
| --- | --- | --- |
| `clear` | 该户「底盘类」网格（石台基 / 地面光圈）水平半径 | 落位半径的**上界**基准 |
| `top` | 底盘顶面高度 | 小品落地的 `y`（不陷进台基、不浮空） |
| `bodyRadius` | 房屋主体网格里"离宅院中心最远"的水平距离 | **不贴墙**退让的基准 |

**环带（显式算出，不做"整段采样再否掉"）**

```
半径下界 = max(clear × 0.72,  bodyRadius + 0.40)
半径上界 = clear × 0.99
若上界 ≤ 下界 → 该户没有可放空间，记为 noRoom 并跳过（不强行塞）
```

- **角度**：直立小品按全周 12 槽均分，每个槽位再顺延重试（矩形房屋的可用方向集中在靠近世界坐标轴的两侧扇区）；
  石板沿"离家向外"方向成线（±0.55 rad），读起来像一条入户石径。
- **不重叠**：小品之间 = 双方水平半径之和 + 0.15m；与既有庭院小品 = 双方半径之和 + 0.10m。
  （既有小品的半径也是实测的：矮篱 1.45m、石粒 0.2m，不能用一个固定间距一刀切。）
- **确定性**：每户用 `home.number` 播种的 mulberry32，同一场景每次得到完全相同的一套摆放 —— 便于复现与自检。

### 为什么"不会阻挡居民"

1. 本项目 webgl 层**本来就没有碰撞系统**（全仓库 `collision/collider/physics` 零命中），本轮也没有引入任何碰撞体/可点击体 —— 自检脚本会断言这一点。
2. 小品只落在**宅基台面**上（半径 ≤ 底盘半径 × 0.99），不越出台基、不侵入坡地；
   环带与**既有**庭院小品（石径 2.55–3.3m、矮篱 3.82m、菜畦 3.5m）同带，不额外侵占任何新的活动范围。
3. 居民漫游半径常量（`RESIDENT_ROAM_RADIUS = 5.5`）、路点算法、`avatarObjects` 一个字符都没改；
   回归套件 `test-resident-roaming.mjs` 与 `verify-courtyard-decor.mjs` 的居民检查都要通过。

### 一个必须记录的坑

`Box3.setFromObject()` 在本场景量出的尺寸与真实值不符（把台基量成 8.59m 而实际 8.45m；
把房屋主体量成 2 倍），且宅院 `group` 带 **-90° 旋转**，**世界轴对齐包围盒会虚胖**（实测 5.32m vs 真实 2.66m）。
所以本轮改为：**手工按顶点 × matrixWorld 量包围盒**，并用「水平半径」而不是包围盒做退让判定 ——
这既绕开了测量偏差，也让判定与旋转无关。

## 5. 实测结果（`node scripts/verify-courtyard-decor.mjs`）

| 指标 | 数值 |
| --- | --- |
| 落位总数 | **238 件**（覆盖 45/50 处宅院 · ≥90%） |
| 分角色 | 石板 70 / 果树灌丛 42 / 石凳 34 / 景观石 32 / 矮竹 24 / 毛石 24 / 石灯 12 |
| 实例网格 | 13 个 `InstancedMesh` · 28 份材质（复用共享贴图） |
| 新增三角面 | **≈ 82,475 ≈ 全场的 16.9%**（本迭代实测基线 487,832） |
| 越出台基 / 侵入主体 / 与既有小品重叠 | **0 / 0 / 0** |
| 未加入 `clickableMeshes` / 碰撞体 | 0 / 0 |
| 控制台报错 | 0 |
| 被挡原因（重试次数） | `wall 0` · `decor 441` · `existing 558` · `noRoom 30` |

> 5 处宅院没有小品：它们的环带已被项目既有的庭院小品（矮篱/菜畦/木料堆）占满，按规则不强行塞入。
> 想提高覆盖，调 `DECOR_GAP` / `PROP_GAP` 即可（会牺牲一点疏朗感）。

**性能约束**：13 个 draw call（实例化后），三角面 +16.9% —— 远低于自检器的
`triangles ≤ 基线 × 1.6` 上限；全部 `MeshStandardMaterial`，**无自定义 shader、无动画、无 render target**。

## 6. 换成 Blender 手工模型（可选）

当前实现是用 three 基础几何程序化拼的（零外部资源、可复现）。若要换成手工模型：

1. 按 `docs/utopia-courtyard-decor-art-prompts.md` 出参考图 → Blender 建模；
2. 导出 GLB（单件 300–800 面、原点在底面中心、无动画）放到
   `frontend/src/virtual-utopia/webgl/models/decor/<role>.glb`；
3. 部署前后用 `node scripts/rollback-manor-deploy.mjs --target decor --backup` / 直接运行回滚；
4. 只需把 `DECOR_RECIPES[role].build` 换成 `loadModel('decor/<role>.glb')` 的几何（落位/材质/自检全部无需改）。
