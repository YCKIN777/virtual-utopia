## 二、Vercel部署步骤

### 2.1 注册Vercel账号
- [ ] 访问 Vercel 官网 (https://vercel.com)
- [ ] 使用GitHub账号登录（推荐）
- [ ] 完成账号设置

### 2.2 导入项目
- [ ] 点击 "New Project"
- [ ] 选择需要部署的Git仓库
- [ ] 配置项目名称

### 2.3 配置构建设置
- [ ] 框架预设：选择 "Other"
- [ ] 构建命令：根据项目需求配置
- [ ] 输出目录：根据项目结构配置
- [ ] 安装命令：npm install

### 2.4 环境变量配置
- [ ] 添加必要的环境变量
- [ ] 配置数据库连接字符串
- [ ] 设置API密钥
- [ ] 配置日志级别

### 2.5 部署项目
- [ ] 点击 "Deploy" 按钮
- [ ] 等待部署完成
- [ ] 获取部署后的URL
